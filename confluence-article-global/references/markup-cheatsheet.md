# Confluence Wiki Markup: шпаргалка соответствий

| Элемент | Markdown | Wiki Markup |
|---|---|---|
| Заголовок раздела | `# Текст` | `h2. Текст` |
| Подраздел | `## Текст` | `h3. Текст` |
| Подподраздел | `### Текст` | `h4. Текст` |
| Жирный | `**текст**` | `*текст*` |
| Курсив | `*текст*` | `_текст_` |
| Моноширинный | `` `код` `` | `{{код}}` |
| Блок кода | ````` ```lang ```` | `{code:language=lang}` … `{code}` |
| Маркированный список | `- пункт` | `* пункт` |
| Вложенный маркер | `  - пункт` | `** пункт` |
| Нумерованный список | `1. пункт` | `# пункт` |
| Горизонтальная линия | `---` | `----` |
| Заголовок таблицы | `\| A \| B \|` + `\|---\|---\|` | `\|\| A \|\| B \|\|` |
| Строка таблицы | `\| 1 \| 2 \|` | `\| 1 \| 2 \|` |
| Внешняя ссылка | `[текст](https://url)` | `[текст\|https://url]` |
| Страница Confluence | `[текст](http://host/pageId=42)` | `[текст\|page:42]` |
| Вложение | `[текст](file.xlsx)` | `[текст\|^file.xlsx]` |
| Ссылка на якорь | `[текст](#anchor)` | `[текст\|#anchor]` |
| Якорь | `<a name="anchor"></a>` | `{anchor:anchor}` |
| Изображение по URL | `![alt](https://url/img.png)` | `!alt\|https://url/img.png!` |
| Изображение-вложение | `![alt](img.png)` | `!^img.png!` |
| Сворачиваемый блок | `<details><summary>Заголовок</summary>` | `{expand:Заголовок}` … `{expand}` |
| Примечание | блок GFM `[!NOTE]` | `{note}` … `{note}` |
| Предупреждение | блок GFM `[!WARNING]` | `{warning}` … `{warning}` |

## Экранирование внутри `{{...}}`

| Символ | Замена |
|---|---|
| `*` | `&#42;` |
| `[` | `&#91;` |
| `]` | `&#93;` |
| `#` | `&#35;` |

## Частые ошибки

| Симптом | Причина | Решение |
|---|---|---|
| «Unknown macro» | `{слово}` вне `{code}` | убрать скобки или переписать словами |
| Таблица поехала | `{code}` или ссылка с `\|` внутри ячейки | вынести блок/ссылку под таблицу |
| Не рендерится жирный | одиночная `*` в тексте | экранировать `~*` или убрать |
| Ссылка битая | `^файл` без вложения | прикрепить файл к странице |
| Заголовок слишком крупный | в документе остался `h1.` | начать с `h2.` |
| Текст слипся | нет пустой строки между абзацами | добавить пустую строку |
